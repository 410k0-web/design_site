# Культ Дизайна — статический сайт (HTML/CSS/JS)

Откройте папку проекта в **Visual Studio 2022** (или любом редакторе) и запустите `index.html`.

## Где менять контент
- Текст: `index.html`
- Стили: `css/style.css`
- Анимация фона: `js/main.js`
- Фото/картинки: папка `assets/`

## Как заменить фото
Замените файлы в `assets/` на ваши изображения и оставьте те же имена:
- `placeholder-hero.svg` (или `.jpg/.png`, просто поменяйте расширение в `index.html`)
- `placeholder-01.svg`
- `placeholder-02.svg`
- `placeholder-03.svg`

## Подсказка по VS 2022
Самый простой способ — открыть `index.html` в браузере.
Если используете расширение Live Server (или любой локальный сервер), сайт будет обновляться автоматически при сохранении файлов.

Удачной верстки.
